# GeminiCLI to API - 项目概述与结构

## 📖 项目简介

GeminiCLI to API 是一个强大的代理服务，将 Google Gemini CLI 转换为 OpenAI 兼容和 Gemini 原生 API 接口。它提供了完整的凭证管理、多模态支持和流式响应处理能力，使开发者能够轻松地将 Gemini 模型集成到自己的应用中。

### ✨ 主要特性

- 🔄 **双端点支持**：同时提供 OpenAI 兼容和 Gemini 原生 API 接口
- 🔐 **灵活认证**：支持多种认证方式和分离密码配置
- 📊 **智能凭证管理**：多凭证自动轮换、负载均衡和故障恢复
- 🌊 **流式响应**：真流式和假流式模式，支持抗截断功能
- 🎛️ **Web 控制台**：完整的 Web 管理界面，支持移动端
- 📈 **实时监控**：使用统计、日志查看和系统监控

## 🏗️ 系统架构

### 核心模块说明

| 模块 | 文件位置 | 主要功能 |
|------|----------|----------|
| **认证和凭证管理模块** | `src/auth.py`, `src/credential_manager.py` | OAuth 2.0 认证流程管理、多凭证文件状态管理和轮换、自动故障检测和恢复 |
| **API 路由和转换模块** | `src/openai_router.py`, `src/gemini_router.py`, `src/openai_transfer.py` | OpenAI 和 Gemini 格式双向转换、多模态输入处理、流式响应管理 |
| **网络和代理模块** | `src/httpx_client.py`, `src/google_chat_api.py` | 统一 HTTP 客户端管理、代理配置和热更新支持、超时和重试策略 |
| **状态管理模块** | `src/state_manager.py`, `src/usage_stats.py` | 原子化状态操作、使用统计和配额管理、文件锁和并发安全 |
| **任务管理模块** | `src/task_manager.py` | 全局异步任务生命周期管理、资源清理和内存管理 |
| **Web 控制台模块** | `src/web_routes.py` | RESTful API 端点、WebSocket 实时通信、移动端适配检测 |

### 高级特性实现

**文件位置**：`src/anti_truncation.py`

实现原理：
- 检测响应截断模式
- 自动重试和状态恢复
- 上下文连接管理
- 智能截断检测算法

核心功能：
- 自动检测回答是否被截断
- 智能重试机制确保完整回答
- 上下文保持和状态恢复

#### 格式检测和转换

**文件位置**：`src/format_detector.py`

实现原理：
- 自动检测请求格式（OpenAI vs Gemini）
- 无缝格式转换
- 参数映射和验证
- 智能格式识别

核心功能：
- 支持 OpenAI messages 和 Gemini contents 格式
- 自动参数映射和验证
- 格式转换透明化

## 📊 数据流架构

```
用户请求 → 格式检测 → 路由分发 → 凭证轮换 → API 调用
    ↓           ↓         ↓         ↓         ↓
响应处理 ← 格式转换 ← 结果解析 ← 错误处理 ← 网络请求
```

### 请求处理流程

1. **请求接收**：Web 框架接收 HTTP 请求
2. **身份验证**：验证 API 密钥和权限
3. **格式检测**：自动识别请求格式（OpenAI/Gemini）
4. **路由分发**：根据格式和端点类型路由到对应处理器
5. **凭证选择**：智能选择最优的可用凭证
6. **API 调用**：向 Google API 发送请求
7. **响应处理**：处理返回数据并进行格式转换
8. **结果返回**：返回用户友好的响应

### 并发处理架构

- **异步 I/O**：基于 asyncio 的高性能异步处理
- **请求池管理**：智能的 HTTP 连接池管理
- **负载均衡**：多凭证负载均衡和故障转移
- **流式处理**：真正的实时流式响应处理

## 📋 支持的模型

### 基础模型

| 模型名称 | 描述 | 特殊功能 |
|----------|------|----------|
| `gemini-2.5-pro` | Gemini 2.5 Pro 模型 | 支持思考模式 |
| `gemini-2.5-pro-preview-06-05` | Gemini 2.5 Pro 预览版 | 支持思考模式 |
| `gemini-2.5-pro-preview-05-06` | Gemini 2.5 Pro 预览版 | 支持思考模式 |
| `gemini-2.5-flash` | Gemini 2.5 Flash 模型 | 快速响应 |
| `gemini-2.5-flash-image-preview` | 绘图模型预览版 | 🎨 图像生成和编辑 |
| `gemini-2.5-flash-image` | 绘图模型 | 🎨 图像生成和编辑 |

### 特色功能

#### 思维模型

- **`gemini-2.5-pro-maxthinking`**：最大思考预算模式
- **`gemini-2.5-pro-nothinking`**：无思考模式

#### 搜索增强模型

- **`gemini-2.5-pro-search`**：集成搜索功能的模型

#### 特殊功能变体

**假流式模式**：在任何模型名称后添加 `-假流式` 后缀
- 例：`gemini-2.5-pro-假流式`
- 用于需要流式响应但服务端不支持真流式的场景

**流式抗截断模式**：在模型名称前添加 `流式抗截断/` 前缀
- 例：`流式抗截断/gemini-2.5-pro`
- 自动检测响应截断并重试，确保完整回答

## 🔄 快速开始

### Docker 部署（推荐）

**基础部署**

```bash
docker run -d --name gcli2api --network host \
  -e PASSWORD=pwd -e PORT=7861 \
  -v $(pwd)/data/creds:/app/creds \
  ghcr.io/zhongruan0522/geminicli2api:latest
```

**Docker Compose 部署**

```yaml
version: '3.8'

services:
  gcli2api:
    image: ghcr.io/zhongruan0522/geminicli2api:latest
    container_name: gcli2api
    restart: unless-stopped
    network_mode: host
    environment:
      - PASSWORD=pwd
      - PORT=7861
    volumes:
      - ./data/creds:/app/creds
```

启动服务：

```bash
docker-compose up -d
```

## 🔧 初始配置

1. **访问 Web 控制台**：`http://127.0.0.1:7861/auth`
2. **登录认证**：使用默认密码 `pwd`（或你设置的密码）
3. **完成 OAuth 流程**：按照指引完成 Google OAuth 认证
4. **上传凭证文件**：在控制台中上传你的 Google OAuth 凭证
